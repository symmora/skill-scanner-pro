# ДИТ-сканер (DIT-scanner)

**ДИТ-сканер** — веб-приложение для сканирования списков навыков/инструментов ИИ-агентов и поиска **вредоносных действий** и **скрытых инструментов**, которыми можно манипулировать агентом.

> **DI**namics of **T**hreats → **ДИТ**: сканер «движений» навыка — обфускация, перехват инструкций, тихая эксфильтрация — ещё до того, как агент выполнит хоть строчку.

Вставьте определение инструмента, MCP-конфига, набора промптов или манифеста расширения — и получите оценку риска **0–100** со списком находок и **цитатами-доказательствами**: каждая находка показывает точный фрагмент текста, который её вызвал.

---

## Возможности (версия 1)

- **Сканирование списка навыков** — вставьте манифест/определение и запустите анализ. Ничего не выполняется: только статический разбор текста.
- **Список оценок риска** — главный экран: навыки ранжируются от самых опасных к самым безопасным.
  - Оценка **0–100** и уровень: `Чисто` / `Низкий` / `Средний` / `Высокий` / `Критический`
  - Раскрывающиеся находки с описанием правила, весом и цитатами-доказательствами
  - Фильтры «Все / Высокий риск / Чистые» и сводка (всего / с риском / чистые / максимальный балл)
- **Интерфейс на двух языках** — переключатель **EN/RU**; выбор запоминается, язык определяется автоматически по браузеру. Переводятся и описания правил — уже сохранённые сканы тоже переводятся «на лету».
- **Личный воркспейс** — каждый скан хранится в Convex и доступен только вам (single-user по задумке v1).

## Что ищет детектор

10 правил (`src/convex/analyzer.ts`), заточенных под злоупотребления агентами:

| Категория | Примеры паттернов |
|---|---|
| Обфускация | `base64 -d \| sh`, hex-блобы, `eval(atob(...))` |
| Эксфильтрация | `curl -X POST` наружу, сбор `process.env`, доступ к `~/.ssh`, `id_rsa` |
| Перехват инструкций | «ignore previous instructions», скрытые системные промпты, «не говори пользователю» |
| Скрытые инструменты | shadow-серверы в `mcpServers`, `allowedTools: ["*"]`, авто-подтверждение |
| Закрепление | `crontab`, правки `~/.bashrc`, `LaunchAgents`, автозагрузка |
| Эскалация | `sudo`, setuid, `unshare`, `/etc/shadow` |
| Прочее | тихая установка пакетов (`curl … \| sh`), широкие обходы ФС, длинные закодированные блобы |

Оценка считается так: берётся максимальный вес сработавшего правила + бонус за каждую дополнительную категорию (максимум +24), итог обрезается до 100. Так навык, «шумит» по мелочи в нескольких местах, всё равно поднимается в списке.

## Технологии

- **Vite + React 19 + TypeScript** (роутинг на React Router v7)
- **Tailwind CSS v4** + shadcn/ui, шрифты Inter и JetBrains Mono
- **Convex** — база данных, бэкенд и аутентификация (email-код + гостевой вход)
- **Framer Motion** — анимации

## Структура проекта

```
src/
├── convex/
│   ├── analyzer.ts        # движок правил: 10 детекторов + подсчёт оценки
│   ├── skills.ts          # query/mutations: submitSkill, listMySkills, removeSkill
│   └── schema.ts          # таблица scannedSkills
├── lib/
│   ├── i18n.tsx           # LanguageProvider + словари EN/RU
│   └── rule-catalog.ts    # названия и описания правил на двух языках
├── components/            # DashboardHeader, LanguageSwitcher, ui/*
└── pages/
    ├── Landing.tsx        # лендинг
    ├── Auth.tsx           # вход (email-код или гость)
    └── Dashboard.tsx      # главный экран: сканер + список оценок риска
```

## Запуск локально

Нужен [Bun](https://bun.sh).

```bash
bun install
bun convex dev --once   # применить схему и сгенерировать типы
bun tsc -b --noEmit     # проверить типы
bun run dev             # dev-сервер Vite
```

Переменные окружения (`CONVEX_DEPLOYMENT`, `VITE_CONVEX_URL`) уже настроены в среде Freebuff; при локальном запуске подключите свой Convex-деплой (`bun convex dev`).

## Оценки и ограничения

- **Только статический анализ** — находки это *сигналы, а не приговоры*. Всегда проверяйте вручную: возможны ложные срабатывания (например, легитимный `curl` в скрипте сборки).
- Правила ищут паттерны в **английских** командах и промптах; русскоязычные фразы-инъекции пока не детектируются (в планах).
- Доказательства (цитаты) не переводятся намеренно — это исходный текст манифеста.
