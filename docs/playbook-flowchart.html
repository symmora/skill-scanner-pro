🛡️ Плейбук анализа на уязвимости

Строгая последовательность: идёшь сверху вниз, на каждом узле — ветка «если → то». Стоп-флаги (🔴) завершают анализ досрочно с вердиктом. Полная версия: docs/analysis-playbook.md.

Этап I — Подготовка

Шаги 0–2
S0Источник
если блог/чат/файл от кого-то → пометить untrusted, настороженность выше
если git без истории/с squash → жёлтый флаг
S1Паспорт анализа — имя, хэш, дата, тип. Без паспорта дальше не идти.
S2Поверхность атаки — что максимум может сделать?
если поверхность пуста → риск 0, стоп

Этап II — Автоскан

Шаги 3–4
S3Скилл-сканер → оценка 0–100
если ≥60 → полный ручной проход
если 1–59 → сокращённый чеклист (S5,7,9,11,13)
если 0 → всё равно ручной, эвристика не истина
S4Разбор находок — по цитате решить
если FP → пометить + обосновать
если сомнение → добить вручную

Этап III — Ручной проход

Шаги 5–14
S5Обфускация
если блоб декодировался в код → 🔴 CRITICAL, стоп
S6Эксфильтрация — сеть + секреты/файлы
если вместе → 🔴 CRITICAL, стоп
если только сеть → WHOIS/репутация доменов
S7Prompt-инъекции
если прямая → CRITICAL для prompt/extension
S8Shadow-инструменты (MCP)
если wildcard/autoApprove → 🔴 HIGH–CRITICAL
S9Persistence
если пишет в автозагрузку → HIGH
S10Эскалация
если sudo/setuid без причины → HIGH
S11Тихая установка
если свежий/тайпсквоттинг пакет → HIGH
S12Широкий доступ к ФС
если вне рабочей папки → MEDIUM–HIGH
S13Сетевые сюрпризы — порты, nc, DNS-туннели
если не объяснимо функцией → HIGH
S14Комбинаторика — безобидные куски вместе = атака
сеть+секреты · инъекция+tools · install+persistence → 🔴 CRITICAL

Этап IV — Вердикт

Шаг 15
CRITICAL → отклонить HIGH → отклонить / жёсткие условия MEDIUM → с ограничениями LOW → наблюдать ЧИСТО → можно
Протокол: вердикт, оценка ± корректировка, находки+FP, уверенность, рекомендация.
